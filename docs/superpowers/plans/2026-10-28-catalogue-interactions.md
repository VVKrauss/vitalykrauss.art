# Catalogue interactions and request inbox implementation plan

**Goal:** implement the twelve requested catalogue, Studio and cart improvements while preserving existing works and publications.
**Architecture:** retain the static public site and authenticated Node/SQLite Studio. A shared public cart module owns localStorage, header dropdown and request submission on both pages. Requests are validated against the published catalogue and stored separately from catalogue drafts; only the owner reads them. About data joins the versioned draft/publication model. Ordered series work IDs and exhibition work/media IDs control presentation.
**Tech stack:** existing vanilla JS/Express/SQLite/Sharp; MIT SortableJS for touch drag reordering; MIT Cropper.js for avatar selection. No payment or outgoing email integration.

- [x] Backend: tests for ordered series, private/public About, safe request snapshots, idempotency and private inbox; implement these boundaries.
- [x] Studio: drag and keyboard reorder controls, About multilingual editor and avatar crop, inbox/bell with read/unread and handled states. Keep existing drafts/prices intact.
- [x] Public: shared persistent cart and checkout modal, responsive fixed-height header/burger, square exhibition covers, author portrait/contact, simplified footer/favicon, cm/in labels, media thumbnails/lightbox with navigation and swipe everywhere.
- [x] Verify real browser click/drop/crop/cart/request flows, reload persistence, mobile widths and swipe; backend tests/build/security checks.
- [ ] Back up/deploy Studio, push public Pages and verify both live endpoints without inserting test requests into production.

Decisions: requests require email only, optional name/note; quantities allowed, no payment, totals in EUR. Store titles/series/exhibition places/sizes/prices at receipt so historical requests remain understandable after edits. Retry uses a stable request ID to prevent duplicates. A failed submission retains cart. Default author portrait uses the supplied photo, circular display with centre square crop; owner can replace and crop in Studio. Footer text exactly “made with love by redflow d”. Email moves into About. Current free font remains; Literata was proposed and is OFL licensed, no unrequested font switch.
